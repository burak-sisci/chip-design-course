# Şartname klasörü

Yarışma şartnamesinin PDF'i bu klasörde **yerelde** durur. Başkasına ait bir belge olduğu için public repoya yüklenmez (`.gitignore`: `docs/sartname/*.pdf`).

Şu an kullanılan: **2026 Çip Tasarım Yarışması Şartnamesi, v1.3** (son kontrol: 2026-11-11)

İndirme yeri: [TEKNOFEST Çip Tasarım Yarışması sayfası](https://www.teknofest.org/en/competitions/chip-design-competition)

Yeni şartname çıkınca: eski PDF'i `eski/` altına taşı, yenisini koy, bu dosyadaki sürüm satırını güncelle ve Claude'dan şartnameyi `docs/mufredat.md` ile karşılaştırmasını iste.
